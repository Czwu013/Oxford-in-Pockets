# 建筑定位及立面依据

建筑平面来自随源码分发的 OpenStreetMap 摘录，保留外轮廓、内环和庭院。坐标以米表示，向东为 x 正、向南为 z 正。学院主场地图和园区地图用来辨认相邻建筑、院落方向、入口和长廊。主场图的北箭头倾斜，转换到项目坐标后才使用。[OpenStreetMap 署名及许可](https://www.openstreetmap.org/copyright) · [学院 2021 年主场地图](https://www.magd.ox.ac.uk/wp-content/uploads/2022/02/Magdalen-Main-Site-July-2021.pdf) · [学院主场和园区图](https://www.magd.ox.ac.uk/wp-content/uploads/2022/09/Magdalen-Maps.pdf)

| 建筑 | 几何和识别依据 |
| --- | --- |
| Great Tower，OSM w77881357 | 临街钟塔使用四个角部塔座的地图位置。学院公布高度为 144 英尺，折合约 43.9 米。四层塔身、四面各一对钟室高窗、透空女儿墙、四角大尖塔和各面中央较矮的尖塔构成剪影。四角各有一面金色风向旗。用学院维修影像辨认顶部，用从 High Street 拍摄的立面照比对整塔及街屋的高差。 |
| Chapel，w38255267；Hall，w77881439 | 礼拜堂是横向前堂与纵长唱诗席拼接的 T 形建筑，紧邻东侧大厅。西面七联窗与下方西门落在 St John's Quad 一侧。简化的五个雕像龛、上下窗格、墙顶压石、凸出扶壁和高窗均为立体细节。 |
| Cloister，r182657 | 内院孔按 OSM 轮廓保留。三面双层建筑与较低的南侧廊道围合草坪。学院俯拍图可辨北侧八组低拱、上层窗、扶壁、齿状女儿墙与长灰顶。拱券有前后表面、内弧和纵深，通道有地面、天花及退后的墙。每组小雕刻表现轮廓，未逐件复原。 |
| Founder's Tower，w77881412；Muniment Tower，w77881383 | 两座塔分别位于回廊西翼与礼拜堂前堂旁。前者保留穿行门道、凸出的多面采光窗、墙垛与角塔，后者用较朴素的墙面、扶壁和低塔冠区分。 |
| New Building，w38255269 | 三层、二十七开间立面、中央五开间的三角山花与底层半圆拱廊。正立面朝南面的大片草坪。学院平面用虚线表示的敞开拱廊补在 OSM 凹入的中段墙线前。 |
| Porters' Lodge，w77881410；沿街排屋 | 门洞沿主入口 n3974478304 和通向院内的方向留空。沿街排屋采用连续双层直棂窗、挑出的方形窗楣、檐口、屋顶小窗与烟囱。大塔顺街道排布，其轴线与礼拜堂、回廊不同。 |
| 桥侧河岸建筑 | 既有场地调查将合并轮廓 w297556577 区分为低矮维修楼屋顶平台，以及带三座山墙和突出窗的 Gentleman Commoners Building。另两处 OSM 轮廓分别绘制 Old Kitchen 的陡山墙与圆窗，以及 Gothicks 沿河的齿状矮墙和三尖顶山墙。各体量按学院地图及调查照片估算立面。 |

## 第二版的建筑和桥

- 大塔钟室的八座高窗直接贯穿外墙。立面投影之内有退后的木百叶、带小孔的下段挡板、竖梃和窗花。钟室檐线上方的女儿墙保留通透栏杆和带花孔的较高垛块。四角大尖塔和四面中央小尖塔各有凹入的盲拱、分层花饰和收尖的石刹。对比高街和学院维修照片后，模型保留大塔四角石尖约 43.9 米、活动平台 35.02 米的设定。平台标高和开口尺寸取自目测比例。[学院顶部特写](https://www.magd.ox.ac.uk/news/raising-the-standard-the-restoration-of-the-great-towers-weather-vanes/) · [High Street 整塔](https://oxfordhistory.org.uk/high/tour/north/magdalen_college.html)
- 礼拜堂的西面七联窗及侧面高窗均建有实体窗洞、后退的玻璃和石制竖梃。西门按修复照片表现五个雕像龛、龛间花饰、两枚盾牌及层叠拱线。玻璃上的灰调人物、盾牌纹样和小像造型由项目绘制，个别圣像、纹章及玻璃画的图案经过简化。唱诗席纵脊和前堂横脊在两道斜天沟处相交。建模窗深约 0.6 至 0.8 米，屋顶坡度按实景估算。[礼拜堂西门近照](https://www.magd.ox.ac.uk/news/magdalen-chapels-west-door-restoration-earns-dual-commendations/) · [学院礼拜堂介绍](https://www.magd.ox.ac.uk/welcome-to-magdalen-college-chapel/)
- 回廊将庭院侧窗柱、券内口、廊内地坪和后墙分层，实际模型通廊深约 3.35 至 3.62 米。拱内可以斜看相邻开间。西侧门洞用交叉拱肋和中央结饰表现雕刻拱顶，其他开间的天花横木和树叶、兽形雕饰轮廓经过简化。New Building 的整齐凹入矩形推拉窗、半圆石拱、三角山花与圆饰依照学院从大塔拍摄的照片制作。[学院俯拍](https://www.magd.ox.ac.uk/news/may-morning-2/) · [Historic England 回廊拱顶结饰](https://historicengland.org.uk/images-books/photos/item/HT08346)
- 莫德林桥的每条水道各有三座主要桥拱，另外分布四座较小步道券和一座较大的岛侧拱。模型按两个水道位置组织十一处开口。转动镜头可见拱筒内侧的径向石缝、扶壁的半圆立柱、突出方石带、分块券石与略凸出的拱心石。栏墙按桥面两端的标高变化起伏。桥墩宽度、拱顶和水面的相对高度、石块分段、污渍分布依据照片估算，岛上开口和牵引道在地形中可能部分遮蔽。[《Oxoniensia》桥梁史研究，Tom Jaine，1971](https://www.oxoniensia.org/volumes/1971/jaine.pdf) · [Historic England 桥梁名录](https://historicengland.org.uk/listing/the-list/list-entry/1369360) · [Alan Hughes 的桥拱下摄影](https://www.geograph.org.uk/photo/6272391)
