# 口袋牛津 · 十四处街区

[English](README.md) · [莫德林英文图册](docs/magdalen-gallery.html) · [全城全景](docs/oxford-panorama.jpg)

下载仓库并解压，双击 `docs/index.html` 可以离线打开地图。

Oxford in Pockets 是一张可以从全城缩到街面的离线 3D 地图。十四处彩色街区共用地图坐标、季节和时钟，外围建筑以灰阶呈现。本版新增高街北侧的皇后学院与皇后巷、南侧的大学学院与逻辑巷。两处校门之间可经有地图记录的过街点和南侧人行道往返。

莫德林沿用独立第二版的 40 个建筑轮廓及原有绘制材质。圣斯威辛庭院、Longwall 庭院、高街临街建筑、植物园入口和大塔共用同一彩色范围。全城视角简化树冠与水面，两级画面采用同一组地理边界。

## 打开街景

用支持 WebGL 2 的浏览器打开交付的 HTML。首次访问直接使用 **English**。点右上角的 **中 / EN** 可改为中文，浏览器会记住后续选择。右上角的「中 / EN」可随时切换，当前地点、镜头、季节和进行中的活动接着运行。地图、模型、纹理、界面和合成音色都在 HTML 内。资料面板中的外部参考链接需要联网。

- **照片模式**　点右上角相机，当前街景会铺满窗口。仍可旋转、平移和缩放，行人、天气和活动继续运行。点左上角「恢复界面」或按 **Esc** 即可返回。

- **地图和镜头**　点彩色街区中的建筑、地图标签或底栏地点进入全景。五处扩建街区的「地标近景」可回到上一版的构图。也可直接进入金十字庭院、叹息桥巷、佩克沃特庭院、利登庭院或纽菲尔德学院。「全城」回到之前的总图取景。拖动旋转，滚轮或双指缩放。双指平移、右键拖动或按住 Shift 拖动可平移地图。
- **日景和夜景**　点底栏的月牙「夜景」进入约 22:36 的模型时间。太阳移向地平线，窗灯和路灯逐渐点亮。再点太阳「日景」回到刚才的白天时刻。过渡约 3.2 秒，途中可以反向切换。自然走时继续运行。五月晨唱、市场开市和汤姆钟各用自己的演出时刻，返回日常即可接回原来的镜头与昼夜。
- **春日树影**　从莫德林选「河岸」再点「椴树下」，可近看稀疏的浅褐旧叶从树冠飘下，在地面停留。秋季有较密的黄叶和赭色叶片。「天气」内的「光束与光晕」控制近景空气散射，树影、柱影和河面亮部跟随同一光源。
- **阿什莫林与卡尔法克斯**　在博蒙特街进入博物馆前庭，或到圣吉尔斯街南端看殉道者纪念碑。从卡尔法克斯十字路口可以近看钟面、黄铜钟和报时人偶，再沿圣奥尔代茨街步行至市政厅入口。钟面与人偶使用全城的模拟时钟。
- **独立地景**　选中任一街区，点「只看此区」直接在当前机位收起周边城市。用「街区全貌」把整块地形收入画面，或切回「完整地图」查看周围环境。「全城」返回记住的总图机位。
- **沿宽街步行**　在贝利奥尔选择「沿宽街到三一」，反方向从三一出发。两种走法共用一条街边路径。步行时地图展开，抵达时选中对面的目的地。拖动镜头或选择其他机位可以提前离开步行。
- **手机竖屏**　地点、四季和昼夜在底栏，机位和显示范围位于其上。一般竖屏显示两行六列地点，360 像素及以下显示三行四列。
- **新学院**　「漫步前庭」沿地图上的铺装环道缓行。「栎树回廊」看冬季依然常绿的老树与钟楼。「回廊内侧」进入南侧木构廊道。「城墙花境」沿园路看城墙与花床。
- **默顿学院**　「走过默顿街」从临街建筑走向礼拜堂。「旧图书馆庭院」站在 Mob Quad 里，可见低矮的石瓦屋顶、礼拜堂塔尖与宝库顶。「院士庭院」面向南翼的四层柱式门楼。
- **博物馆**　在春夏看雨燕掠过西立面、转弯减速、收翼钻入石板屋面上的通风罩，稍后从同一巢口飞出。秋冬可以观察空置巢口。「走近西门」沿草坪进馆方向前行，「玻璃大厅」从上方看铸铁承托的分跨屋顶。
- **牛津城堡**　全景保留圣乔治塔、旧监狱和土丘的方位与尺度。沿 Castle Yard 走向塔身，或在「旧监狱」看 D 翼和圆形债务人塔。从丘顶可以回望方塔和监狱群。
- **原有四处**　进莫德林回廊或 Addison’s Walk，点大塔参加五月晨唱。在广场看圆顶、北阶和周边柱廊。在有顶市场可步入巷内、揭开屋顶、体验清晨开市。穿过基督堂汤姆门可以看水池和四周平台，或开启夜间 101 响钟声。
- **季节和声音**　四季、自动轮换、雨后地面与降雪使用独立控件。降雪逐渐停积于屋面和地表。五月晨唱和汤姆钟默认静音，进入活动后可开启原创合成音。活动结束或提前返回会恢复之前的镜头与日常状态。

在小屏竖屏上，点底部街区选择器可直接跳到十四处中的任一处。高街沿线有九个建筑与庭院近景。选择「穿过高街到大学学院」或反方向行程，可以经同一个地图过街点往返。

## 从源码构建

需要 Node.js、Three.js 0.180.0 与 esbuild 0.28.2。地图和模型的已处理版本随源码提供。

```sh
npm ci
npm run build
```

默认生成 `dist/index.html`。运行 `npm run build:pages` 更新 `docs/index.html`。GitHub Pages 可以直接使用默认分支下的 `/docs`。用 `node build.mjs path/to/output.html` 指定输出。已有离线工具链时，`NODE_PATH` 可指向含 Three.js 的依赖目录，`POCKET_ESBUILD` 可指向 esbuild 二进制。

地图原点位于西经 1.24645°、北纬 51.75190°，X 向东、Z 向南，单位为米，覆盖约 1.665 × 1.350 公里。使用 Python 3 与 Shapely 2.1 从内置 OSM 摘录重新生成派生数据。运行顺序为全城底图、核心建筑细节、外围街区。

```sh
python geo/prepare.py geo/central-oxford.osm.gz
python geo/prepare-details.py
python geo/prepare-quarters.py
python scripts/verify-plan.py --out verification/plan.json
python scripts/verify-quarters-plan.py --out verification/quarters-plan.json
```

模型修改后保留原点、朝向和单位，以相同文件名导出应用变换的 GLB，再用 `python scripts/pack-model.py 文件名.glb` 压入资源目录。汤姆塔、圆顶阅览室与博物馆西立面的原始子网格另带短距离环境遮蔽属性，可在 Blender 后台运行 `blender -b -P scripts/bake-relief.py -- src/assets/tom.gz src/assets/radcliffe.gz src/assets/museum.gz` 重新生成。石板巢口、玻璃屋架和城堡几何由源码生成。

## 回归检查

随源码提供的 `verification/` 记录本次实跑结果。其余脚本可用于复测旧机位、风雨与声音。可以用 Playwright 和本地 Chromium 重新运行。使用环境变量 `POCKET_BROWSER` 与 `POCKET_PLAYWRIGHT` 可指定浏览器和依赖位置。

```sh
node scripts/verify-fourteen.cjs dist/index.html verification/fourteen
```

十四处版用交付 HTML 的文件入口验证了断网启动、英语首屏和语言记忆、十四处在原机位切换独立街区、高街双向步行、九个新近景、同机位四季、昼夜、雨后地面与积雪开关、五月晨唱退出还原，以及手机触控模拟。雨燕和声音另有历版回归脚本。建筑与生境的资料、量算和估绘范围详见 `SOURCES.md`。本轮设备检查使用桌面 Chrome 和手机尺寸的触控模拟。

本包对应用和地标原创部分提供 MIT 许可。OSM 数据、Poly Haven 贴图和英国环境署的高程信息分别列在[素材署名](CREDITS.md)和[模型清单](models/PROVENANCE.md)中。
